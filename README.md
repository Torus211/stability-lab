# Устойчивость системы с запаздывающим датчиком

Лабораторная на C++ и Python: исследуется, как задержка измерения влияет на устойчивость системы с пропорциональным регулятором.

## Модель

```text
a2*x'' + a1*x' + a0*x = b0*u
u(t) = k*(1 - x(t - tau))
```

Цель — единичная ступень. Начальное состояние и предыстория нулевые. По умолчанию `a2=a1=a0=b0=1`, `k=2`; коэффициенты и шаг `dt=0.005` меняются в начале `main.cpp`.

Программа заменяет производные обратными разностями, рассчитывает выход `x(t)` и аналитически находит первую критическую задержку из характеристического уравнения. Для базовых коэффициентов `tau_critical ≈ 0.56764`. При `tau=0.45` колебания затухают, при `tau=0.68` — растут. Устойчивый выход стремится к `2/3`: пропорциональный регулятор оставляет статическую ошибку.

## Файлы

- `main.cpp` — расчёт и запись двух CSV.
- `plot.py` — построение двух графиков из CSV.

Запуск не зависит от редактора: подходят VS Code, Visual Studio и обычный терминал. Все команды выполняются **в папке с `main.cpp` и `plot.py`**.

## Windows: Visual Studio или VS Code

Установить Visual Studio с компонентом **«Разработка классических приложений на C++»**, а также Python 3.9+.

Открыть папку проекта в редакторе. Для сборки использовать **Developer PowerShell for Visual Studio**: в Visual Studio — меню **«Вид → Терминал»** и профиль Developer PowerShell; для VS Code можно открыть Developer PowerShell отдельно и перейти в папку проекта.

```powershell
cl /std:c++17 /EHsc /utf-8 main.cpp /Fe:lab.exe
.\lab.exe
```

Ввести задержку через точку, например `0.45`. После окончания расчёта:

```powershell
py -m pip install matplotlib
py plot.py
```

Если команда `py` недоступна, заменить её на `python`.

## macOS / Linux

Нужны компилятор C++17 и Python 3.9+.

```sh
c++ -std=c++17 -O2 main.cpp -o lab
./lab
```

Ввести задержку, затем выполнить:

```sh
python3 -m pip install matplotlib
python3 plot.py
```

Matplotlib устанавливается один раз. Если Python требует виртуальное окружение: `python3 -m venv .venv`, затем активировать его командой `source .venv/bin/activate` и повторить установку.

## Результаты

- `trajectory.csv` — время и выход системы для введённой задержки.
- `critical.csv` — граница задержки в зависимости от `a1` при `a2=0.5`, `1`, `1.5`.
- `graphs.png` — оба графика на одном изображении.

Повторный запуск перезаписывает результаты. Чтобы сравнить разные задержки, сохранить файлы под другими именами перед следующим запуском.

Задержка округляется до ближайшего шага сетки; фактическое значение выводится в консоль. Разностная схема добавляет численное затухание, поэтому вблизи границы полезно уменьшить `dt`. В CSV значение `-1` означает отсутствие найденной конечной границы и на графике пропускается.
